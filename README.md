Retrieval-Augmented Generation

RAG is one of my main areas of technical interest.

A typical retrieval pipeline can be represented as:

User Query
    │
    ▼
Query Rewriting
    │
    ▼
Hybrid Retrieval
(Vector Search + BM25)
    │
    ▼
Reranking
    │
    ▼
Relevant Context
    │
    ▼
LLM
    │
    ▼
Generated Answer

RAG Concepts

Stage| Technologies / Concepts
Documents| Document Processing
Preparation| Chunking
Representation| Embeddings
Retrieval| Vector Search · BM25
Retrieval Strategy| Hybrid Retrieval
Ranking| Reranking
Context| Context Selection
Generation| Large Language Models
